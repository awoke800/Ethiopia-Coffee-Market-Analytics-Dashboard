# ☕ Ethiopia Coffee Market Analytics Dashboard and Dynamic upload and anlaytics dashboard
## 📌 Project Overview
The Ethiopia Coffee Market Analytics Dashboard is an interactive data visualization and analytics application developed using Python,
Streamlit, Pandas, and Plotly. The dashboard enables users to explore Ethiopian coffee market data through dynamic filters,
key performance indicators (KPIs), trend analysis, forecasting, and automated market insights.

This project was developed as a Data Science portfolio project to demonstrate skills in data cleaning, exploratory data analysis,
dashboard development, and business intelligence
## 🚀 Features
* Interactive dashboard built with Streamlit
* Dynamic filtering by year, warehouse, and coffee type
* Real-time KPI cards
* Coffee price trend analysis
* Monthly trading volume analysis
* High vs. Low price comparison
* Production year performance analysis
* Automated market insights
* Forecasting of future coffee prices
* Download filtered datasets
## 📊 Dashboard Analytics
The dashboard provides insights into:
* Average Closing Price
* Highest Market Price
* Trading Volume (Ton)
* Coffee Symbol Performance
* Warehouse Performance
* Monthly Market Trends
* Price Forecasting
* Market Summary Insights
